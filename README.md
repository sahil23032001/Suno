# सुनो — Suno Hindi Reader

Open a Hindi PDF on your phone and it reads the pages aloud, sentence by
sentence, using the device's own Hindi text-to-speech voice. The PDF never
leaves the phone — everything happens in the browser.

- Page-by-page reading with auto-advance
- Speed, pitch and voice selection
- The sentence being spoken is highlighted, and the word inside it
- Remembers where you stopped in each document
- Warns you when a PDF is a scan, or when its font drops Hindi matras

## Deploy to GitHub Pages

Everything Pages needs is already built into `docs/`. There is no build step
to run on the server and no Actions workflow.

### 1. Create the repository

On github.com click **New repository**, name it `suno` (any name works), keep
it **Public**, and create it without a README.

### 2. Push this folder

```bash
cd suno-hindi-reader
git init
git add .
git commit -m "Suno Hindi Reader"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/suno.git
git push -u origin main
```

If you would rather not use the command line: on the empty repo page click
**uploading an existing file**, then drag in this whole folder.

### 3. Turn on Pages

Repository → **Settings** → **Pages**:

| Field  | Value                    |
| ------ | ------------------------ |
| Source | Deploy from a branch     |
| Branch | `main`                   |
| Folder | `/docs`                  |

Click **Save**. The first deploy takes about a minute.

### 4. Open it

```
https://YOUR-USERNAME.github.io/suno/
```

On Android, open that in Chrome → menu → **Add to Home screen**. It gets the
सुनो icon and opens full-screen without the browser bars.

> **Note on the free tier.** GitHub Pages is free for public repositories:
> 1 GB of storage, 100 GB of bandwidth per month, 10 builds per hour. This
> site is about 1.5 MB, so those limits are not a concern. Private
> repositories need a paid plan for Pages — keep the repo public.

## Before it will speak

Android needs a Hindi voice installed, or it will read Devanagari with an
English voice and it will sound wrong.

1. **Settings** → search for **Text-to-speech**
2. Set the engine to **Google Speech Services**
3. Open its settings and install the **Hindi** voice data

The gear panel in the app lists every Hindi voice it can find, with a
**Test voice** button.

## What works and what does not

**Works:** PDFs that contain real text — anything generated by Word, Google
Docs, LaTeX, a report tool, an export. If you can select the text in a normal
PDF viewer, this app can read it.

**Does not work:** scans and photographs of paper. There is no text in those,
only pixels; reading them would need Hindi OCR. The app detects this and says
so rather than showing a blank page.

**Partly works:** some PDFs embed fonts with an incomplete Unicode map, so
matras (ि ी े ो ं) extract as nothing and words come out wrong. The app
detects this too and suggests re-exporting the original document as PDF, which
almost always fixes it.

There is no MP3 export. Browser speech synthesis plays audio but does not
expose it as a file; saving an actual audio file needs a paid cloud TTS
service.

## Repository layout

```
docs/                     what GitHub Pages serves — the deployable site
  index.html              the whole app
  pdf.min.js              pdf.js (Mozilla, Apache-2.0)
  pdf.worker.min.js       pdf.js parsing worker
  manifest.webmanifest    home-screen name, icons, standalone display
  icon-*.png              app icons
  .nojekyll               skip Jekyll processing

template.html             the source the app is built from
build.py                  builds docs/ and suno.html from the template
assets/                   icon sources
suno.html                 single-file build, no server needed
```

`suno.html` is the same app compressed into one file with pdf.js inlined. Open
it straight off a USB stick or send it over WhatsApp — no hosting involved.

## Rebuilding after an edit

Edit `template.html`, then:

```bash
npm install                # fetches pdfjs-dist
python3 build.py           # writes docs/ and suno.html
git add -A && git commit -m "update" && git push
```

Pages redeploys on push.
